## Proposed Scenario B resize repair

The goal was narrowed to one change: resize oversized source images before CloudConvert creates the cleaned PDF.

Official Make behavior was checked after earlier incorrect assumptions:

- Router branches do not merge back into one shared downstream module.
- Make's If-else and Merge flow is intended for conditional branches that rejoin.
- Make Image Resize accepts image files, not PDFs.

### Current edited Scenario B design

After Google Drive Download `[12]`:

1. If-else `[40]`
   - First condition intended as:
     - `12. Mime Type`
     - `Starts with`
     - `image/`
   - Else handles non-image files.
2. Image Resize `[32]` on the image branch.
3. Do Nothing on the Else branch.
4. Merge `[46]` rejoins the two branches.
5. CloudConvert Create a Job `[8]` consumes Merge output.

### Image Resize `[32]` mapping

- Data: `12. Data`
- File name: `12. Name`
- Preserve aspect ratio
- Resize according to maximum height
- Height: `2048`

Maximum height was chosen so portrait images do not exceed Make Image's documented output-height limit.

### Merge `[46]` outputs

`Name`

- If image condition is true: `32. File name`
- Else: `12. Name`

`Data`

- If image condition is true: `32. Data`
- Else: `12. Data`

### CloudConvert `[8]` intended mapping

Upload file:

- Data: `46. Data`
- File name: `46. Name`

Conversion task:

- Format: `I don't know the input format`
